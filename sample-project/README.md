# LM Code Demo Sample Project

This sample project is intentionally tiny and safe. It gives the public demo a believable context target without using private product code, customer code, local paths, or repository history.

## Included scenario

The demo uses a fictional session refresh helper with one deliberately simple bug:

```text
The refreshed session returns the old expiry value.
```

The public demo may reference this scenario for:

- task mode examples
- mock project context
- read-only patch preview
- sample test ideas

## Safety boundary

Do not replace this folder with real private source code. Public demo samples should stay small, fictional, and reviewable.
