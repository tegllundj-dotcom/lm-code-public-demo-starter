# Privacy Statement

LM Code Public Demo is intended to demonstrate a local-first AI coding workflow.

## Public demo privacy rules

The public demo should not collect telemetry by default.

The public demo should not upload source code, prompts, file names, project paths, or model responses to any external service.

The public demo should not require a cloud account.

The public demo should not include analytics unless clearly disclosed and opt-in.

## LM Studio

The intended workflow uses a local LM Studio server selected by the user. In demo mode, LM Studio behavior may be mocked to keep the release safe and reproducible.

## Local data

A public demo build should use bundled sample data or mock state only.

It should not read arbitrary folders or real repositories unless the build is explicitly changed from demo mode and the user is clearly warned.

## Commercial product note

Commercial versions may include licensing, update checks, or team administration features. Those features should be documented separately before release.
