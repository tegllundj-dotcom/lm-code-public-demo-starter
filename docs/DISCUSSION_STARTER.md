## Longer version

```text
I am experimenting with a local-first AI coding workflow for Windows and LM Studio.

The project is called LM Code.

It is not trying to be a fully autonomous coding agent. The angle is more controlled:

- task modes
- visible context
- local model workflow
- read-only patch previews
- human review before action
- no hidden file mutation
- no automatic project scanning

The public build is mock/sample-data only and safe by design.

I am trying to validate whether developers actually want a separate local AI coding workbench beside their IDE.

Feedback questions:
1. Would this workflow be useful?
2. Would you trust a local-first coding workbench more than a cloud agent?
3. What would you need before using it on real code?
4. Is Windows + LM Studio a useful niche?
```
