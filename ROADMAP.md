# LM Code Public Demo Roadmap

This roadmap describes the public demo and feedback surface only. The commercial LM Code product core remains private.

## Current public milestone

```text
Public demo + installer preview
```

The public demo is intended to show the workflow direction safely:

- task modes
- visible context
- mock/local model behavior
- read-only patch preview
- human review
- no file writes
- no real project scanning
- no patch apply
- no telemetry by default

## Near-term priorities

### 1. Public demo clarity

- make demo mode unmistakable
- improve README and release notes
- add screenshots
- add short demo video
- improve first-run explanation

### 2. Installer feedback

- collect Windows install feedback
- document warnings clearly
- improve release notes
- add checksum guidance
- separate installer issues from workflow feedback

### 3. Workflow validation

- validate whether developers want a separate local AI coding workbench beside their IDE
- validate task modes
- validate read-only patch preview usefulness
- collect safety expectations

### 4. B2B and public-sector pilot readiness

- prepare pilot proposal
- prepare security/privacy overview
- prepare data-flow note
- prepare risk register
- prepare installation guide

## Future product direction

These are product roadmap intentions, not commitments in the public demo:

- stronger LM Studio integration
- richer task modes
- project context selection
- better patch preview
- optional controlled apply flow
- team workflow controls
- license/activation flow
- private deployment support

## Not in the public demo

- commercial product source code
- automatic project scanning
- hidden file mutation
- patch apply
- licensing system
- private deployment tooling
- team/admin controls
- updater infrastructure

## Core rule

Open-source trust. Sell workflow.
