# Contributing

Thanks for helping improve the LM Code public demo.

This repository is the public demo and feedback surface for LM Code. It is not the commercial product source tree.

## Good contributions

Useful contributions include:

- README improvements
- public demo wording improvements
- bug reports
- installer feedback
- accessibility feedback
- safety/privacy wording improvements
- screenshots or documentation suggestions
- clear feedback on the local AI coding workflow

## Do not submit

Please do not submit:

- private product source code
- customer code
- personal project code
- secrets, tokens, keys or credentials
- private repository URLs
- local absolute paths that reveal sensitive information
- code that writes to user files
- code that scans real projects automatically
- patch-apply behavior
- telemetry by default

## Public demo boundary

The public demo must remain:

- mock/sample-data only
- read-only
- non-destructive
- clear about demo mode
- free of private source code

## Pull requests

Before opening a pull request, check:

- no private data is included
- links work
- screenshots are safe
- wording does not overclaim security, privacy or compliance
- the change supports the public demo purpose

## Security and privacy wording

Be precise. Do not claim compliance or security guarantees unless they have been independently verified.

Use language such as:

```text
Designed to support controlled evaluation.
```

Avoid language such as:

```text
Compliant by default.
```

## Core rule

Open-source trust. Sell workflow.
